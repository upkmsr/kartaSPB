# SPRINT 12 — Medical

Статус: **DONE**. Предметная область спринта — медицинские объекты
Санкт-Петербурга. Реализован реальный initial import; SPRINT 13 не входит в эту
поставку.

## Данные и модель

Снимок OpenStreetMap от 2026-09-16 содержит 5 503 элемента. В PostGIS
импортированы 5 248 именованных физических объектов, в том числе 2 286 аптек,
972 стоматологии, 392 лаборатории и 154 больницы. Для 255 объектов источник
явно указывает `opening_hours=24/7`, для 43 — признак emergency. В снимке
присутствуют филиалы «СМ-Клиники» и «Немецкой семейной клиники»; эти сети не
служат списком разрешённых организаций.

Каждый OSM node/way/relation получает стабильный canonical ID и отдельную
точку PostGIS. `medical_facilities` хранит тип учреждения, собственность,
адрес, контакты, часы работы, источник и confidence. Сеть или оператор,
если указаны в данных, хранится в `medical_organizations`; филиалы сети не
объединяются в одну точку. `medical_services` содержит 789 записей услуг и
специализаций из исходных тегов. Raw записи, staging, запуски импорта и
provenance использует общий Data Platform. Повторный импорт обновляет объекты
без дублей.

Собственность подтверждена для 28 государственных и 284 частных объектов.
У 4 936 объектов она остаётся `unknown`: название клиники само по себе не
считается доказательством. Оценка confidence отражает заполненность полей,
а не качество медицинской помощи. Рейтинг и отзывы не выдумываются.

## API и карта

- `GET /api/medical` — bbox, тип учреждения, собственность, `is_24h`,
  `limit` и `offset`.
- `GET /api/medical/pharmacies.geojson?bbox=...` — обязательная область
  просмотра, не более 3 000 объектов за запрос.
- Медицинские учреждения и аптеки имеют отдельные записи в Layer Registry.
  Категории дают фильтры по медицинскому подтипу. Аптеки загружаются при
  включённом слое по текущей области карты и кластеризуются MapLibre, без
  общего массива всех аптек в React. Выбор открывает canonical Object Card.

## Воспроизведение

```bash
docker compose up --build --wait
docker compose exec backend python -m app.medical
docker compose exec backend alembic current
docker compose exec backend alembic heads
docker compose run --rm -e RUN_DB_TESTS=1 backend pytest -q
```

После импорта `current` и `heads` равны `0010_medical`.
Подробности об источнике, лицензии и ограничениях находятся в
[data-sources.md](data-sources.md).

## Ограничения

OSM не является полным официальным реестром. Адреса, часы работы и
специализации могут быть неполными или устаревшими. Опубликованный
[реестр ТФОМС](https://spboms.ru/sistema-oms/meditsinskim-organizatsiyam/)
рассмотрен как официальный источник, но не совмещён с OSM-точками без
надёжного сопоставления физических филиалов. Модуль не заменяет оперативную
информацию медицинских организаций и служб экстренной помощи.
