# SPRINT 9 — Surface Transport

Статус: **DONE**. `app.transport` импортирует наземные маршруты и остановки
с независимыми слоями и базовым пространственным анализом.

## Результат

- Детерминированная выборка OSM содержит 9 направленных маршрутов: по три
  автобусных, трамвайных и троллейбусных, а также 441 отдельную остановку.
  Маршруты — MultiLineString, остановки — Point.
- Для маршрутов сохраняются тип, номер и указанные в источнике направления;
  остановки хранят ссылки на обслуживающие маршруты. Общий pipeline записывает
  стабильные OSM ID, staging и provenance.
- Layer Registry отдельно управляет автобусами, трамваями, троллейбусами и
  остановками. `GET /api/analysis/transport/nearby?lon=...&lat=...` возвращает
  ближайшие остановки и подсчёт объектов в радиусе по PostGIS.

## Воспроизведение и проверка

```bash
docker compose exec backend python -m app.transport
docker compose run --rm -e RUN_DB_TESTS=1 backend pytest -q tests/test_transport.py
```

Тест проверяет 450 объектов, повторный импорт без новых дублей, валидность
геометрии и nearby API. Источник: [data-sources.md](data-sources.md).

## Ограничение

Выборка не представляет всю сеть города. Расписание и маршрутизация отсутствуют;
nearby использует расстояние по прямой, а не время поездки.
