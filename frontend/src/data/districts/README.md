# Saint Petersburg districts

Static development snapshot of the 18 `admin_level=5` OpenStreetMap relations
for Saint Petersburg. Retrieved through a single Nominatim lookup on 2026-09-15.
The runtime serves this local GeoJSON and does not call Nominatim.

`docs/data-sources.md` for the relation list, source URLs, freshness limits, and
the replacement path for a future PostGIS/API source.
