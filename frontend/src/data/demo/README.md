# Demo fixture — SPRINT 1

`point.json` содержит ровно один GeoJSON Feature (Point) с ID `demo-object-1`.
Координаты взяты из примера в команде владельца для SPRINT 1.
Это искусственный development fixture, не сведения о реальном городском объекте.
Он включён в демонстрационный frontend, но не импортируется в PostGIS или production dataset.
